# Прогноз до итоговых запусков / 实验前预测

本文件在本次正式训练及 test 评估之前提交，不根据新结果修改。此次为相同固定协议的重新运行，预测参考了此前实验经验，不属于首次探索的盲预测。旧的 test 划分已在先前版本中被评估过，本次不会宣称它是从未见过的新测试集；不根据旧 test 结果改变搜索空间、模型选择标准或新运行结果。

1. 基础配置在 val 上约为 94–97%；seed 1–5 的最大值减最小值预计在 0.3–1.5 个百分点之间。随机初始化、批次顺序会改变决策边界。
2. 40 次 Optuna 搜索中最佳 trial 的 val 准确率预计比基础配置 seed 0 高 0–2 个百分点；也可能没有改善。较大的网络或学习率可能加快 30 轮内收敛，过高学习率和过大 dropout 可能降低表现。
3. 最佳 trial 在新 seed 上的平均 val 表现可能降低，因为选优利用了 seed 0 和同一验证集的偶然优势。test 上优势预计更小，未必五个 seed 都为正且超过基础配置的随机波动。
4. MedianPruner 预计停止 30–70% trial，节约约 20–60% 训练轮数。没有剪枝的运行时间只是反事实估计，不把估计当作实测。

## 固定的实验方案

- 数据：load_digits，split_seed=0，分层 1077/360/360，特征除以 16。
- 实验 1：repeatability，seed 0 两次；base_seeds，seed 1–5；比较 seed 1 和 2 的错误转移。
- 实验 2：顺序 TPE(seed=42)，40 个 trial，训练 seed=0；完成 10 个 trial 后有计划暂停，重新启动补齐至 40。按作业附录，重启不恢复 sampler 的随机数状态，不声称与不中断搜索等价。
- 实验 3：只按搜索末轮 val_acc 选择最佳配置，冻结 configs/best.yaml 后，再以 seed 101–105 对基础/最佳配置进行配对 test 评估，共 10 次；每个 seed 先 base 后 best。
- test 在实验 3 之前不评估；之后不调参、不重选配置。
- 所有失败和剪枝记录保留，失败不补跑、不挑选成功重复。
- 基础波动定义为实验 1 五个 seed 的 val_acc 极差；只有五个 test 差值均为正且每个大于该极差，才按作业判据称改善稳定。

## 对说明中计时与复现要求的解释

history.csv 必须记录真实 epoch_s，因此不同运行无法逐字节相同。预测文件要求字节完全相同；history 的 epoch/train_loss/val_loss/val_acc 要求完全相同，epoch_s 单独保留为实际测量值，不伪造为一致。本差异会如实写入报告。
