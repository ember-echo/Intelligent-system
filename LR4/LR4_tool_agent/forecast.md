# Прогноз до holdout

На коротких задачах с одним очевидным инструментом ожидается близкая успешность. ReAct должен чаще выигрывать, когда прочитанный результат определяет, какой инструмент нужен дальше. Фиксированный план может справиться, если по результату меняются только аргументы уже выбранного инструмента. Возможные ошибки плана — пропуск шага поиска, преждевременно выбранная операция записи и неверное связывание аргументов.

После сокращения избыточных шагов ожидается, что медиана суммарных входных токенов плана окажется на 20–50% ниже ReAct. На одношаговых задачах выигрыш может исчезнуть из-за отдельных вызовов планирования и итогового ответа. ReAct может тратить больше вызовов при ошибочных аргументах и повторных попытках.

30 задач holdout запускаются по одному разу на режим, порядок режимов чередуется. Оба режима работают с одной моделью и общими лимитами. После начала holdout промпты не меняются.
